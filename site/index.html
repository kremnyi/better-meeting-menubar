Video, audio, a Markdown transcript, and JSON with timings, languages, and speakers, saved to ~/Documents/Better Meetings.

  • Open formats. Edit the transcript in any editor, and search still finds your changes.
  • Export bundles. Adds up to 30 screenshots, on-screen text read with Apple's Vision framework, and a combined timeline.

Transcription

Two on-device engines. Pick the one that fits.

Both run with Core ML on Apple silicon. Models download once from Hugging Face and then work offline.

Parakeet v3

Default

One fast pass with automatic language detection and punctuation.

  • Languages25 European languages, including Ukrainian, Russian, and English
  • PassesOne pass over the whole recording
  • ModelAbout 470 MB, downloaded once

Runs through FluidAudio · Model weights CC-BY-4.0, © NVIDIA

Whisper

Most languages

For every other language, and for meetings that switch between them.

  • LanguagesEvery language WhisperKit lists
  • PassesOne per selected language, merged by confidence, with a silence filter
  • ModelsSmall, Large v3 Turbo (about 1.6 GB), or Large v3, plus vocabulary hints and tunable decoding

Runs through WhisperKit by Argmax

Speaker labels

Speaker 1Speaker 2

Optional. SpeakerKit tells voices apart on your Mac and labels each transcript segment. It adds about 11 MB of models and some processing time.

In the details

Built so a recording is never lost.

Calendar-aware

Shows today's meetings from Calendar, with a button that records and names the next one. Reads events and never edits them. Off by default.

Detect meetings

Once another app has used the microphone for half a minute, you get a notification offering to record. Nothing is recorded until you click.

Silence warning

If no audio arrives from either source within 30 seconds, an amber warning appears while there's still time to fix the input.

Resumable

Finished transcription passes are cached. If processing fails or you quit, pick up from the saved recording, even after a restart.

Automatic titles

Unnamed meetings get a title like “Anna — Pricing Review”, found on-device with Apple's NaturalLanguage framework.

Verified updates

Sparkle checks GitHub and verifies each update before installing it. Automatic downloads and the beta channel are both opt-in.

Privacy

What stays on your Mac, and what doesn't.

Your meetings never leave the Mac unless you move them. The network is used for exactly two things.

On your Mac

  • Screen, system audio, and microphone recordingsLocal
  • Transcripts and speaker labelsLocal
  • Screenshots and on-screen textLocal
  • Meeting titles and searchLocal
  • Calendar event detailsLocal

Over the network

  • Update checksGitHub
  • Speech models, once per modelHugging Face

That's the full list. Better Meeting has no analytics or telemetry and doesn't use an account.

Install

Ready in a minute.

Install with Homebrew or download the app from GitHub Releases. Xcode isn't required.

Homebrew

The cask downloads the release from GitHub and verifies its SHA-256 checksum.

$ brew tap --custom-remote kremnyi/better-meeting https://github.com/kremnyi/better-meeting-menubar
brew install --cask kremnyi/better-meeting/better-meeting
open -a "Better Meeting"

Staying current. The app can update itself from Options → App & updates. With Homebrew, quit the app and run brew upgrade --cask kremnyi/better-meeting/better-meeting.
