# Security

Better Meeting records screens and audio and keeps everything on the Mac. If you find a way to make it leak, upload, or expose that data, or any other vulnerability, please report it privately.

## Reporting

Use **Report a vulnerability** on the repository's [Security tab](https://github.com/kremnyi/better-meeting-menubar/security/advisories/new). Include the app version from **About**, your macOS version, and steps to reproduce. You will get a reply within a week, and a fix ships as a regular release with credit in the notes if you want it.

Please do not open a public issue for security problems.

## Scope

The latest stable release and the current beta receive fixes. Releases are self-signed; verify a download with the SHA-256 file next to it, or install through Homebrew, which checks the sum for you.
